# Release manifests

A release manifest pins a set of additions at exact versions, so that an implementer can
claim support for a known quantity. See [`../../VERSIONING.md`](../../VERSIONING.md) §2.

**A published manifest is immutable.** Corrections ship as the next release. The only
permitted edit to a published manifest is an erratum note pointing at its successor.
