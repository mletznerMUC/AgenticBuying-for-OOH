## What this release is

An inventory, in versioned and reviewable form, of every OOH-specific concept a
production DOOH media owner had to invent privately in order to sell programmatically —
each one lifted out of the transport into a transport-neutral definition, and bound back
down to both a programmatic and an insertion-order representation.

It is not yet a specification. It is the complete problem statement, in a shape that can
become one.

## Known limitations

1. **Unverified against upstream.** No addition's proposed placement has been checked
   against a current AdCP or AAMP revision. Every placement is a hypothesis.
2. **Two sources unretrievable.** The Creative Pre-Approval API docs and the DSP adapter
   spec were blocked by network egress policy. ADD-008 is materially incomplete without
   the first — the rejection reason-code taxonomy is the single most important unknown in
   this release.
3. **One media owner, one market.** Everything here is Ströer, Germany, digital screens.
   Generalisation to other media owners and markets is untested; the market-applicability
   sections of the additions are largely empty.
4. **No classic OOH.** Printed posters and billboards are absent entirely, because the
   source documents are about digital screens. This is the largest gap.
5. **Eight source inconsistencies unresolved**, recorded in
   [`../../analysis/open-gaps.md`](../../analysis/open-gaps.md).
6. **Offer/IO bindings are new and unreviewed.** The JSON sketches are illustrative
   shapes, not schemas. No schema has been written.

## Path to R2

In rough priority order:

1. Resolve the R1 blockers: retrieve the two specs, get answers to the eight questions
   for Ströer in `open-gaps.md` §3.
2. Verify placements against current AdCP and AAMP revisions; correct
   [`../../mapping/`](../../mapping/) in the same pass.
3. Promote the highest-value additions to `review`, then `stable`, and write the first
   OEPs in [`../../proposals/`](../../proposals/).
4. Widen the evidence base: a second media owner, ideally in another market, to test
   which additions are universal and which are Ströer-specific.
5. Cover the R1 gaps: classic/static OOH, availability and holds, privacy, sustainability
   (see the coverage table in [`../REGISTRY.md`](../REGISTRY.md)).
